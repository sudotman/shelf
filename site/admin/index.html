Look after the shelf from any browser.

Add books, fix titles, move things between shelves. Every change is saved to sudotman/shelf on GitHub, and the site rebuilds itself in about a minute.

  1. Create a fine-grained token. The link fills in the name and the permissions (Contents: Read and write, Actions: Read); under Repository access, choose Only select repositories and pick shelf.
  2. Generate it and paste it below.

The token stays in this browser and is only ever sent to api.github.com. Without “remember”, it is forgotten when this tab closes. A remembered token can be read by other pages on this domain, so only remember it on your own devices.
